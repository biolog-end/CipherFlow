# 🔐 CipherFlow - Нодовый Шифратор

**CipherFlow** - это интерактивный веб-приложение для создания сложных схем шифрования с помощью визуального программирования нодами. Создавайте, комбинируйте и делитесь своими уникальными алгоритмами шифрования!

## ✨ Основные возможности

### 🎯 Реализованные функции

- **✅ Визуальный редактор нодов** - перетаскивайте и размещайте блоки шифрования
- **✅ Система соединений** - связывайте ноды для создания цепочек обработки
- **✅ Режим резки соединений** - удаляйте соединения интерактивно (кнопка ножниц или клавиша X)
- **✅ Режим шифрования/дешифрования** - переключение направления обработки
- **✅ Разнообразные алгоритмы шифрования**:
  - Шифр Цезаря с настраиваемым сдвигом
  - **Шифр Виженера** - полиалфавитное шифрование с ключевым словом
  - Код Морзе с улучшенной поддержкой русского и английского языков
  - **Зачаровыватель планет** - шифрование через координаты городов мира
  - Шифр A1Z26 - замена букв на числа
  - Морзе (Бинарный) - кодирование в 0 и 1
  - **Морзе (Кошачий)** - забавное кодирование с мяy, брмяy, мрряy
  - Преобразование чисел в слова (русский/английский)
  - Математические операции над числами
  - Обращение текста
  - Изменение регистра
- **✅ Умное сохранение схем** - с названиями и описаниями
- **✅ Автосохранение** - автоматическое сохранение работы
- **✅ Горячие клавиши** - быстрое управление
- **✅ Интерактивная справка** - клик по логотипу или F1
- **✅ Адаптивный дизайн** - работает на всех устройствах
- **✅ Современный UI/UX** - темная тема и плавные анимации

## 🚀 Начало работы

### Запуск приложения

1. Откройте `index.html` в современном веб-браузере
2. Приложение автоматически инициализируется
3. При первом запуске появится интерактивный туториал

### Основные действия

1. **Создание нодов**: Перетащите нод из левой панели на рабочую область
2. **Соединение нодов**: Кликните на точку вывода и перетащите к точке ввода
3. **Настройка параметров**: Измените значения в полях нодов
4. **Ввод текста**: Введите текст в нижней панели или в ноде "Ввод текста"
5. **Просмотр результата**: Результат отображается в правой части нижней панели

## 🔧 Типы нодов

### Входные/Выходные
- **🔽 Ввод текста** - источник данных для цепочки
- **🔼 Вывод текста** - отображение финального результата

### Классические шифры
- **🔄 Шифр Цезаря** - сдвиг букв алфавита на заданное количество позиций
- **🛡️ Шифр Виженера** - полиалфавитное шифрование с ключевым словом (множественные входы)
- **📡 Код Морзе** - преобразование текста в код Морзе с улучшенной поддержкой языков
- **🌍 Зачаровыватель планет** - уникальное шифрование через координаты городов мира
- **🔢 Шифр A1Z26** - замена букв на их позиции в алфавите
- **🔗 Секретное слово** - генерация ключевых слов для других алгоритмов

### Специальные режимы Морзе
- **⚫ Морзе (Бинарный)** - кодирование морзе в бинарные символы (0/1)
- **🐱 Морзе (Кошачий)** - забавное кодирование с кошачьими звуками

### Преобразования
- **#️⃣ Числа в слова** - замена цифр на их словесное представление
- **🧮 Математика** - арифметические операции над числами в тексте
- **↩️ Обратить текст** - реверс всего текста или отдельных слов
- **📝 Регистр** - изменение регистра букв (верхний, нижний, заглавные)

## ⌨️ Горячие клавиши

| Клавиши | Действие |
|---------|----------|
| `Ctrl/Cmd + S` | Сохранить схему с диалогом имени |
| `Ctrl/Cmd + O` | Загрузить схему |
| `Ctrl/Cmd + N` | Новая схема |
| `Delete` | Удалить выбранный нод |
| `Escape` | Снять выделение / Отменить соединение |
| `F1` | Показать справку |
| `X` | Включить/выключить режим резки соединений |
| `+` / `=` | Увеличить масштаб |
| `-` | Уменьшить масштаб |
| `Ctrl/Cmd + 0` | Сбросить масштаб |

## 🎮 Управление мышью

| Действие | Управление |
|----------|------------|
| **Перетаскивание нодов** | Левая кнопка мыши на ноде |
| **Создание соединений** | Левая кнопка на точке соединения → перетащить к другой точке |
| **Разрыв соединений** | Shift + правая кнопка на точке соединения |
| **Резка соединений** | Режим резки (X) + клик по соединению |
| **Панорамирование** | Средняя кнопка / Правая кнопка / Ctrl + левая кнопка |
| **Масштабирование** | Колесо мыши |
| **Удаление нода** | Кнопка × на ноде |
| **Справка** | Клик по логотипу CipherFlow |

## 🔄 Режимы работы

**Режим шифрования** (по умолчанию):
- Данные проходят слева направо
- Алгоритмы работают в прямом направлении

**Режим дешифрования**:
- Направление стрелок меняется
- Алгоритмы автоматически инвертируются
- Например, шифр Цезаря со сдвигом +3 становится сдвигом -3

## 💾 Формат файлов схем

Схемы сохраняются в JSON формате и содержат:

```json
{
  "version": "1.0",
  "created": "2024-01-01T00:00:00.000Z",
  "nodes": [
    {
      "id": "node_0",
      "type": "input",
      "x": 100,
      "y": 100,
      "data": { ... }
    }
  ],
  "connections": [
    {
      "id": "connection_0",
      "from": "node_0",
      "to": "node_1"
    }
  ]
}
```

## 🌟 Примеры использования

### 1. Простое шифрование
```
[Ввод] → [Шифр Цезаря] → [Вывод]
```

```
[Ввод] → [Текст]     ↘
                      [Шифр Виженера] → [Вывод]

```

```
[Ввод] → [Морзе (Кошачий)] → [Вывод]
Результат: "мяy мрряy мяy мрряy брряy мяy"
```

### 6. Многоуровневое шифрование
```
[Ввод] → [A1Z26] → [Числа в слова] → [Зачаровыватель планет] → [Вывод]
```

## 🤝 Как поделиться схемой

1. Создайте свою схему шифрования
2. Нажмите кнопку "Сохранить схему" (Ctrl+S)
3. **Введите название и описание** схемы в диалоге
4. Поделитесь полученным JSON файлом с метаданными
5. Другие пользователи могут загрузить его через "Загрузить схему" (Ctrl+O)
6. При загрузке будет показано название и описание схемы

### 💡 Советы по созданию схем

- **Давайте осмысленные имена** схемам (например: "Двойной Цезарь с морзе")
- **Добавляйте описания** для сложных схем
- **Используйте Шифр Виженера** для серьезного шифрования
- **Комбинируйте алгоритмы** для усиления защиты
- **Тестируйте в режиме дешифрования** - переключите тумблер и проверьте результат

## 🆕 Новые возможности (2024)

### 🛡️ Шифр Виженера
Реализован классический полиалфавитный шифр с двумя входами:
- **Текстовый вход** - для исходного текста
- **Ключевой вход** - для ключевого слова (можно подключить нод "Секретное слово")
- Поддержка русского и английского алфавитов
- Автоматическое переключение в режиме дешифрования

### 🌍 Зачаровыватель планет
Уникальный алгоритм шифрования через географические координаты:
- **База данных городов** - сотни городов России и мира
- **Режимы языков** - русский, английский или смешанный
- **Координатная система** - каждая буква заменяется координатами случайного города на эту букву
- Пример: `п` → `53.1945, 45.0196` (Пенза)

### ✂️ Режим резки соединений
Интерактивное удаление соединений между нодами:
- **Кнопка ножниц** в панели управления канвасом
- **Горячая клавиша X** для быстрого переключения
- **Визуальная подсветка** соединений под курсором
- **Точное определение** попадания по линии соединения

### 🐱 Улучшенный кошачий морзе
Обновленные звуки для более реалистичного "кошачьего языка":
- `.` (точка) → `мяy` 
- `-` (тире) → `мрряy`
- `/` (пробел) → `брряy`

### 📡 Многоязычный морзе
Различные символы для русского и английского морзе:
- **Русский**: `·` и `−` (Unicode символы)
- **Английский**: `.` и `-` (ASCII символы)
- Корректное декодирование смешанного текста

## 🐛 Известные ограничения

- Максимальная длина текста для обработки: без ограничений (зависит от браузера)
- Поддерживаемые браузеры: современные версии Chrome, Firefox, Safari, Edge
- Автосохранение работает только в рамках одного браузера/устройства
- Зачаровыватель планет: ограничен доступными городами в базе данных
