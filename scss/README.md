# 🎨 CipherFlow SCSS Architecture

Этот каталог содержит модульную SCSS архитектуру для приложения CipherFlow, заменяющую единый CSS файл на компонентную структуру.

## 📁 Структура проекта

```
scss/
├── main.scss                 # 🚪 Точка входа - импортирует все компоненты
├── base/                     # 🏗️ Базовые стили
│   ├── _variables.scss       # 🎨 CSS переменные + SCSS переменные  
│   ├── _reset.scss          # 🔄 Глобальный сброс стилей
│   ├── _responsive.scss     # 📱 Адаптивные стили
│   └── _scrollbars.scss     # 📜 Кастомные скроллбары
├── layout/                   # 📐 Структурные компоненты
│   ├── _app.scss            # 🏠 Основная структура (.app)
│   ├── _main.scss           # 📄 Главный контент (.main-content)
│   └── _workspace.scss      # 🖼️ Рабочая область и канвас
├── components/               # 🧩 UI компоненты
│   ├── _header.scss         # 🔝 Заголовок приложения
│   ├── _toggle.scss         # 🔄 Переключатель режимов
│   ├── _buttons.scss        # 🔘 Кнопки
│   ├── _panel.scss          # 📋 Боковая панель нодов
│   ├── _node.scss           # 🔗 Ноды на канвасе
│   ├── _connections.scss    # 🌐 Соединения между нодами
│   ├── _input-output.scss   # 📝 Панель ввода/вывода
│   ├── _canvas-controls.scss # ⚙️ Управление канвасом
│   └── _tooltips.scss       # 💬 Всплывающие подсказки
└── utils/                    # 🛠️ Утилиты и помощники
    ├── _mixins.scss         # 🎛️ Миксины (медиа-запросы и т.д.)
    ├── _animations.scss     # ✨ Анимации и эффекты
    ├── _modes.scss          # 🔄 Режимы работы (шифровка/дешифровка)
    └── _special-effects.scss # 🎭 Специальные эффекты
```

## 🚀 Команды для сборки

### Установка зависимостей
```bash
npm install
```

### Разработка (автосборка с отслеживанием изменений)
```bash
npm run dev
# или
npm run watch:css
```

### Продакшен сборка (сжатие)
```bash
npm run build:css
```

## 🔧 Конфигурация

### package.json scripts:
- `build:css` - Создает сжатый CSS файл для продакшена
- `watch:css` - Отслеживает изменения и автоматически пересобирает (режим разработки)
- `dev` - Алиас для `watch:css`

### SCSS компилятор:
- **Препроцессор**: Dart Sass (последняя версия)
- **Выходной файл**: `css/style.css` (заменяет оригинальный)
- **Source maps**: Автоматически создаются для отладки
- **Сжатие**: В продакшен режиме (`--style=compressed`)

## 📝 Как редактировать стили

### 1. Найдите нужный компонент
- **Заголовок** → `components/_header.scss`
- **Ноды** → `components/_node.scss` 
- **Панель инструментов** → `components/_panel.scss`
- **Соединения** → `components/_connections.scss`
- **Адаптивность** → `base/_responsive.scss`

### 2. Внесите изменения
Редактируйте файлы в каталоге `scss/`, **не** в `css/style.css`

### 3. Пересоберите
```bash
npm run build:css
```
Или используйте автосборку:
```bash
npm run dev
```

## 🎨 Переменные и темы

### CSS Custom Properties (в `base/_variables.scss`):
```scss
:root {
    --bg-primary: #0f0f23;
    --accent-primary: #7c3aed;  
    --text-primary: #f8fafc;
    // ... и другие
}
```

### SCSS переменные:
```scss
$bg-primary: var(--bg-primary);
$accent-primary: var(--accent-primary);
```

### Breakpoints:
```scss
$breakpoints: (
    mobile: 768px,
    tablet: 1024px, 
    desktop: 1200px
);
```

## 🔄 Адаптивные миксины

### Использование:
```scss
.my-component {
    width: 100%;
    
    @include media(mobile) {
        width: 50%;
    }
    
    @include media(tablet) {  
        width: 75%;
    }
}
```

## ⚠️ Важные моменты

### 1. Порядок импортов важен!
В `main.scss` сначала идут переменные и миксины, потом компоненты.

### 2. Используйте переменные
```scss
// ✅ Хорошо
background: $bg-primary;

// ❌ Плохо  
background: #0f0f23;
```

### 3. Вложенность SCSS
```scss
.node {
    background: $bg-primary;
    
    &:hover {
        background: $bg-secondary;
    }
    
    .node-title {
        font-weight: 600;
    }
}
```

### 4. Не редактируйте `css/style.css` напрямую
Этот файл генерируется автоматически и перезаписывается при каждой сборке.

## 🔍 Отладка

### Source Maps
При включенном source map в браузере вы увидите исходные SCSS файлы вместо скомпилированного CSS.

### Verbose режим
Для подробного вывода ошибок:
```bash
sass scss/main.scss css/style.css --verbose
```

При добавлении новых компонентов:

1. Создайте файл в `components/_new-component.scss`
2. Добавьте импорт в `main.scss`
3. Используйте существующие переменные и миксины
4. Протестируйте сборку командой `npm run build:css`
