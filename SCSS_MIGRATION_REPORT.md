## 📝 Инструкции для дальнейшей работы

### ✅ Что теперь нужно делать:
1. **Редактировать** файлы в `scss/`, а НЕ в `css/style.css`
2. **Использовать** переменные вместо hardcoded значений
3. **Запускать** `npm run build:css` после изменений
4. **Использовать** `npm run dev` для разработки

### ❌ Что НЕ нужно делать:
1. Редактировать `css/style.css` напрямую (файл перезаписывается)
2. Удалять `css/style.css.backup` (резервная копия оригинала)
3. Коммитить `node_modules/` (добавлено в .gitignore)

### 🔍 Поиск стилей:
- **Заголовок** → `scss/components/_header.scss`
- **Ноды** → `scss/components/_node.scss`
- **Панель** → `scss/components/_panel.scss`
- **Адаптивность** → `scss/base/_responsive.scss`
